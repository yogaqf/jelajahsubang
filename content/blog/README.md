# Blog Content (MDX)

Simpan artikel blog dalam format `.mdx` di folder ini.

Format frontmatter yang disarankan:

```md
---
title: "Judul Artikel"
slug: "judul-artikel"
excerpt: "Ringkasan singkat artikel"
date: "2026-05-05"
author: "Nama Penulis"
tags: ["wisata", "subang"]
published: true
---
```

Gunakan nama file sesuai slug, contoh: `panduan-wisata-subang.mdx`.
